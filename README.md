# holycat
Fyve28's personal Linux system information dashboard.
## Preview
![](https://i.ibb.co/TDFB8bW3/image.png)
## Features
This Bash script will display the user, hostname, OS, kernel alongside hardware, storage, and environment information of your Linux system.
(Everything is in the screenshot above.)
## Requirements
Since this has been only tested on Ubuntu in WSL (check Known limitations), those two are obvious required. This script is a Bash script, so Bash is required as well.
## Installation
Inside your terminal, simply use `git clone https://github.com/Fyve28/holycat.git` or `gh repo clone Fyve28/holycat` (if you are using gh).
Execute the script by `./holycat.sh`.
## Configuration
Feel free to modify the code however you want to customize the look.
(There are comments inside that will hopefully make the formatting easier.)
## Known limitations
Since this has been only tested on Ubuntu in WSL, whether if this is compatible with other systems is still unsure.
